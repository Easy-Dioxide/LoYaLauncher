Features

强大，藏在简单背后

从下载到进游戏的每一步，我们都替你认真想过。你只需要做一件事：开始游戏。

离线即玩

自定义用户名与皮肤，无需任何账号，UUID 遵循 Mojang 规范，双击即玩。

全版本覆盖

从远古 rd-132211 到最新正式版与快照，五步幂等安装，中断后可续装。

全新下载中心

版本搜索、类型筛选与详情卡片，一键安装；镜像源即时切换，下载任务实时可见。

自动 Java 管理

按游戏版本自动匹配合适的 Java，缺失时自动下载，全程无感。

实例系统

一套版本，多个隔离实例。各自独立的 mods、config 与 saves，互不打扰。

Mod 生态

Modrinth 海量 Mod 搜索即装，一键启用 / 禁用，也可随时导入本地 jar。

整合包

一键导出实例为 .zip 整合包分享给朋友；导入即重建实例，含防目录穿越校验。

微软正版登录

设备码 OAuth 流程，完整令牌链自动续期；未购游戏等场景均给出中文指引。

基岩版支持

Windows 平台完整支持：官方版本库浏览、UWP 安装与启动，双版一键切换。

FAQ

常见问题

离线模式无需微软账号，仅本地生成符合 Mojang 规范的 UUID 与用户名，不发送任何账号信息，适合单机与局域网联机。如需正版联机与皮肤展示，请使用内置的微软账号登录。

Java 版从 2009 年的 rd-132211 到最新正式版与快照均可一键安装；基岩版当前完整支持 Windows 平台（UWP 安装与启动），macOS / Linux 为实验性路线图。

在 Mod 页面搜索 Modrinth 即点即装，可随时启用 / 禁用或导入本地 jar；Fabric / Forge / NeoForge / Quilt 四大加载器一键安装。整个实例可一键导出为 .zip 整合包，朋友导入即可复刻你的世界。

下载中心内置 BMCLAPI 镜像与 Mojang 官方源自动互备，也支持切换自定义镜像源；镜像链某一步失败会自动回退下一个源，断点续传不重复传输。

所有数据保存在用户目录下的 .loya 文件夹中，包含游戏实例、Java 运行时、日志与配置。启动前会自动进行磁盘、内存、Java 环境自检；卸载启动器不会误删你的世界。
