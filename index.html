Features

为"玩"而生的每一处细节

从离线即玩到正版联机，从自动 Java 到 Mod 自由装配，一应俱全。

离线即玩

自定义用户名与皮肤，无需任何账号。UUID 严格遵循 Mojang 离线规范，双击即玩。

全版本覆盖

从远古 rd-132211 到最新正式版与快照，五步幂等安装流程，中断后可无缝续装。

全新下载中心

版本搜索、类型筛选、镜像源一键切换（BMCLAPI / 官方 / 自定义），安装链路加固。

自动 Java 管理

按游戏版本自动推断所需 JDK，系统缺失即从清华镜像自动下载 Temurin，全程无感。

实例系统

一套版本可创建多个隔离实例，各自独立的 mods / config / saves，互不干扰。

Mod 生态

Modrinth 海量 Mod 搜索、安装、启用/禁用、本地 jar 导入；四大加载器一键安装。

整合包

一键导出实例为 .zip 整合包分享；导入即重建实例，含防目录穿越校验。

微软正版登录

设备码 OAuth 流程，完整令牌链自动续期，支持正版服务器联机，安全存于本地。

玻璃拟态设计系统

深空渐变底 + 磨砂卡片 + 渐变强调色；交错入场、涟漪扫光、弹性指示条、背景氛围柔光。

FAQ

常见问题

默认位于用户目录下的 ~/.loya。所有版本、实例、Mod 与日志均按此结构隔离存储，卸载时删除该目录即可干净清理。

下载中心支持镜像源一键切换：BMCLAPI、Mojang 官方、或自定义源地址，切换即时生效。国内用户使用 BMCLAPI 镜像通常能显著提升速度。

通常不需要。启动器会按游戏版本自动推断所需 JDK（如 1.21+ 用 Java 21），系统缺失时自动从清华大学 Adoptium 镜像下载并托管，全程无感。你也可以在 Java 管理页手动下载任意主版本。

LoyaLauncher 是第三方启动器。离线模式无需账号即可游玩，微软正版登录则支持正版服务器联机。它不替代官方账号，而是提供更自由的版本管理、Mod 装配与实例隔离。本项目与 Mojang / Microsoft 无任何关联，请支持正版。

基岩版在 Windows 上提供完整支持：可浏览官方版本数据库、安装并启动 UWP 包。macOS / Linux 的实验性支持已在路线图中。
