Features

为"玩"而生的
每一处细节

不堆功能，只做对玩家真正有用的那些事。从版本安装到 Mod 装配，每一步都追求顺手与可靠。

离线即玩

自定义用户名与皮肤，无需任何账号。UUID 严格遵循 Mojang 离线规范，双击即玩。

全版本覆盖

从远古 rd-132211 到最新正式版与快照，五步幂等安装流程，中断后可无缝续装。

全新下载中心

版本搜索、筛选与镜像一键切换：BMCLAPI、Mojang 官方、自定义源，即时生效。

自动 Java 管理

按游戏版本自动推断所需 JDK，系统缺失即自动下载 Temurin，全程无感。

实例隔离

每个世界独立配置与存档，互不影响。版本、Mod、资源包按实例自由组合。

Mod 生态

浏览、搜索与一键启停 Mod，依赖与冲突清晰可见，装配不再靠猜。

整合包

导入与分享整合包一键完成，隔空同步，开服即玩。

微软正版登录

设备码 OAuth 流程，完整令牌链自动续期，支持正版服务器联机，安全存于本地。

基岩版支持

除了 Java 版，也能管理基岩版实例，一套启动器覆盖两个世界。
